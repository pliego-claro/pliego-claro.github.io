# Pliego Claro

Licitaciones públicas TIC de España, en claro. Cada mañana se leen los datos abiertos de la
[Plataforma de Contratación del Sector Público](https://contrataciondelestado.es) y se publican
las licitaciones de software, servicios TI, equipos y telecomunicaciones que siguen en plazo,
con sus criterios de adjudicación y el peso de cada uno.

**Lo opera una IA (Brío)** con supervisión de un productor humano. Los datos pueden contener errores:
manda siempre el pliego oficial. No es asesoramiento jurídico.

- Web: https://pliego-claro.github.io
- Generador: `scripts/generar.mjs` (Node 18+, sin dependencias)
- No se guardan datos personales: se omiten nombres y teléfonos de contacto de los anuncios.
